Tether

The HTTP workbench that feels like your Mac.

Chain requests, keep your workspace as plain files, and never make an account.

↑↓ navigate ↵ open esc clear

Reuse any response field in the next request.

Click a value in a response and Tether writes a reference for it. The next request resolves it from the latest run, and Tether won’t send while a reference is unresolved.

Recreated from Tether’s built-in demo workspace, which calls httpbin.org.

Your workspace is a folder you can commit.

Save to a folder and every collection, request and environment becomes a small JSON file. Review changes in a pull request, and pull a teammate’s edits; Tether picks them up when the window regains focus.

Secrets never touch the folder. They stay in the system keychain.

Every action has a key.

Agents run your requests. They never see your keys.

Tether speaks MCP, so Claude, Cursor or OpenCode can call your saved requests by name. Tether fills in auth from your environment and keychain, runs the request, and hands back a trimmed result.

  • Off by default. Grant access per request and per environment.
  • Reads run, writes ask. POST, PUT, PATCH and DELETE wait for your click.
  • Nothing hidden. Every agent run lands in History with the agent’s name.

First launch: these builds aren’t signed yet

macOS. This build isn’t notarized yet, so the first time, right-click Tether in Applications and choose Open. Or clear the quarantine flag:

xattr -dr com.apple.quarantine /Applications/Tether.app

Windows. If SmartScreen appears, choose More info, then Run anyway.

Linux. Make the AppImage executable, then run it:

chmod +x Tether-Linux-x86_64.AppImage

Prefer to build it yourself? Get the source on GitHub and run pnpm tauri build.
